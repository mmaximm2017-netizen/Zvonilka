# Звонилка 0.1: стартовый прототип

Цель: Samsung A15 SM-A155F, Android 16, One UI 8.5 (по скриншоту заказчика).

Это исходники, не готовый APK. Сборка и тест на устройстве ещё не выполнены.
Реализованы клавиатура, редактирование номера, долгое нажатие 0 для +,
удержание удаления для очистки и передача номера системной звонилке.
Прямой вызов пока НЕ реализован: после зелёной кнопки требуется подтверждение
в Samsung Phone. Приложение не запрашивает доступ к контактам и истории,
не назначает себя звонилкой по умолчанию, не отправляет данные в сеть.

## Сборка

JDK 17, Android SDK 35, Gradle 8.11.1:

    gradle :app:assembleDebug :app:lintDebug

Либо загрузить содержимое этой папки в отдельный GitHub-репозиторий и
запустить Actions → Build APK. Workflow подготовлен, но не запускался.
Результат: app/build/outputs/apk/debug/app-debug.apk.
Отладочный APK не предназначен для публикации.

## Следующий этап

1. Успешная сборка и проверка клавиатуры на телефоне.
2. InCallService, роль звонилки, уведомление входящего звонка и экран вызова.
3. Проверка блокировки экрана, двух SIM и восстановления после ошибок.
4. Контакты, история, Т9 и остальное согласованное ТЗ.
