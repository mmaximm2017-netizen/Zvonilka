# Звонилка 0.2

Проверяемый этап ROLE_DIALER + InCallService для Samsung A15, Android 16.
Прототип 0.1 проверен владельцем на телефоне. Версия 0.2 требует проверки на устройстве.

Реализовано:
- назначение приложением телефона по умолчанию через системный RoleManager;
- обработка ACTION_DIAL с номером и без него: номер только подставляется;
- исходящий вызов отдельной кнопкой через TelecomManager.placeCall;
- InCallService, экран входящего/исходящего/активного вызова;
- уведомления CallStyle на Android 12+, полный экран при блокировке при наличии разрешения;
- приём, отклонение, завершение, микрофон, выбор доступного аудиовыхода;
- удержание, DTMF, переключение между одновременно полученными вызовами;
- выбор SIM, когда Telecom запрашивает выбор телефонного аккаунта;
- кнопки громкости отклоняют входящий вызов, когда открыт экран вызова.

Рингтон воспроизводит Android Telecom, сервис не объявляет владение рингтоном.
Экстренные вызовы передаются через Telecom, их обслуживает системная звонилка.
Интерфейс пока на Android Views. Контакты, история, Т9, свайп приёма и датчик
переворота относятся к следующим этапам. Это ещё не полная замена Samsung Phone.

## Проверка APK

1. Установить APK; открыть «Настроить звонки», выбрать Звонилку по умолчанию,
   разрешить вызовы, уведомления и полноэкранные уведомления при запросе.
2. Исходящий обычный звонок: набор, завершение с обеих сторон, микрофон,
   динамик, возврат из уведомления, DTMF в голосовом меню.
3. Входящий вызов при открытом приложении, поверх другого приложения и при
   заблокированном экране: звук, принять, отклонить, завершить удалённо.
4. Если доступны: две SIM с выбором «Всегда спрашивать», ожидание второго
   вызова и возврат к удержанному, Bluetooth и проводная гарнитура.
5. Повернуть экран и свернуть приложение во время разговора; состояние
   должно сохраниться. Завершённые вызовы удаляются из уведомлений.
6. В системных настройках приложений по умолчанию можно вернуть Samsung Phone.

Не использовать экстренные номера для тестирования.

## Сборка

JDK 17, Android SDK 35, Gradle 8.11.1:

    gradle :app:assembleDebug :app:lintDebug --no-daemon

GitHub Actions → Build APK → artifact `zvonilka-debug`.
Отладочная подпись создаётся runner'ом. При несовпадении подписей с ранее
установленной сборкой Android потребует удалить старый прототип перед установкой.
Постоянная приватная подпись для обновлений пока не настроена.

Основание: https://developer.android.com/reference/android/telecom/InCallService
