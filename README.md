# Звонилка 0.3

Нативная звонилка для проверки на Samsung A15 / Android 16.
Техническая база: Kotlin 2.1.20, Jetpack Compose, Material 3, Android Telecom.

## Реализованный пакет

- Три вкладки: Недавние (стартовая), Контакты, Клавиши; системная светлая/тёмная тема.
- Каждая запись CallLog отдельно: тип, цвет, дата, время, длительность, доступная метка SIM.
- Раскрытие записи, повторный звонок, копирование, переход к контакту.
- Выбор записей долгим нажатием, подтверждение выбранного/полного удаления.
- Алфавитный список локальных RawContacts, поиск по имени/номеру, буквенная навигация.
- Внутреннее создание/редактирование имени, нескольких номеров, основного номера, фото из галереи.
- Карточка: фото-баннер, звонок, внешний SMS, копирование, редактирование, история и подтверждение удаления.
- Почти полный свайп вправо (82%) для звонка; возврат короткого свайпа; влево ничего не удаляется.
- T9 с русскими и латинскими буквами; результат только подставляет номер; зелёная кнопка звонит отдельно.
- Долгое 0 для +, удаление/полная очистка, вставка удержанием поля номера, нормализация российского 8/+7.
- SIM по умолчанию, выбор удержанием зелёной кнопки, память фактически использованного аккаунта после соединения.
- Фото-фон с center crop на экране вызова; приём и отклонение длинным свайпом.
- Ответ из баннера открывает CallActivity; mute, динамик, аудиовыход, DTMF, удержание, добавление вызова.
- Датчик приближения во время активного разговора через разговорный динамик, если датчик поддерживается.
- Переворот после наблюдавшегося положения экраном вверх запрашивает silenceRinger у Telecom.
- Собственные уведомления пропущенных: объединение по номеру, закрытие, обратный вызов.
- Открытие Недавних убирает уведомления пропущенных.
- Ручной VCF: экспорт имён и номеров; подтверждаемый импорт UTF-8 v3/v4 (до 5 МБ, 2000 контактов).
- Исправления очистки зависших уведомлений 0.2.1 сохранены.

## Границы и незавершённые пункты ТЗ

- SIM-01..07: прямое чтение/объединение/редактирование SIM-контактов не реализовано. Отображаются только контакты
  с account_type NULL или Samsung `vnd.sec.contact.phone`. Google/другие аккаунты не изменяются и не копируются.
- CON-08: выбор/замена фото есть; ручной crop пока отсутствует. Фото отображается с center crop.
- REC-09/10: долгий тап включает выбор; действия удаления находятся на панели, отдельного меню ⋮ пока нет.
- MIS-04: уведомления убираются; цифровой бейдж вкладки пока не реализован.
- INC-07: поворот из вертикального положения сразу экраном вниз без замеченного положения вверх не распознаётся.
- INC-08: принудительное немедленное выключение дисплея после отклонения не реализовано.
- CALL-04: финальная длительность показывается около секунды; точность при завершении в фоне требует проверки.
- SET-01: VCF переносит имена/номера, не фотографии. Импорт не заменяет записи и может создать дубликаты;
  при ошибке пишет число уже добавленных контактов. Сложные/старые vCard с quoted-printable не поддерживаются.
- SET-02/03: еженедельные копии и ротация трёх файлов не реализованы.
- CID-01..05: онлайн-поставщик не выбран; онлайн-запросы отсутствуют, INTERNET не запрашивается.
- compileSdk/targetSdk остаются 35, minSdk 29; выполнение на Android 16 требует реального теста.
- Постоянная подпись APK не настроена: может потребоваться переустановка и повторные разрешения.
- Репозиторий на момент разработки публичный. Настройка приватности не изменялась.

## Приёмка

На реальном телефоне необходимо проверить до постоянного использования:
1. Роль звонилки, права на контакты/журнал/телефон/уведомления и полноэкранные уведомления.
2. Исходящий, входящий при блокировке и поверх другого приложения; оба способа завершения, пропущенный.
3. Фото, длинные свайпы, физические кнопки громкости, переворот, датчик приближения.
4. Mute, динамик, DTMF, Bluetooth, удержание/второй вызов, две SIM, возврат в исходное приложение.
5. Контакт с двумя номерами: создать, сменить основной, добавить фото, изменить, удалить с подтверждением.
6. История: отдельные записи, цвета, раскрытие, свайп, подтверждение удаления, уборка пропущенных.
7. VCF на тестовых контактах: экспорт/импорт, русский текст, несколько номеров.

Не звонить на экстренные номера ради проверки. Экстренный UI обслуживает предустановленная звонилка.

## Сборка

JDK 17, SDK 35, Gradle 8.11.1:

    gradle :app:testDebugUnitTest :app:assembleDebug :app:lintDebug --no-daemon

GitHub Actions → Build APK → `zvonilka-debug`.

## 0.3.1: диагностика стандартного экрана на Samsung

На Samsung A15 Android 16 подтверждён показ системного экрана при назначенной роли Звонилки. Точная причина пока не установлена. Эта сборка отделяет ошибки уведомления от обработки Telecom и открытия CallActivity, отменяет старое уведомление перед сменой его канала, сохраняет ограниченный локальный журнал подключения службы, состояний и ошибок. Настройки → Диагностика звонков → Копировать. Журнал не содержит номеров, имён контактов и сообщений исключений; автоматически никуда не отправляется. Обработчик необработанного исключения передаёт управление штатному обработчику Android. Требуется повторить обычный исходящий вызов на устройстве и проверить экран/журнал; сборка не является подтверждённым исправлением причины.

## 0.3.2: качество фото

Экран звонка и большой баннер контакта асинхронно читают RawContacts.DisplayPhoto вместо растягивания DATA15 (миниатюры). Размер декодирования ограничен 2048 пикселями по длинной стороне без увеличения маленького исходника; списки продолжают использовать миниатюры. При отсутствии большого фото или доступа остаётся миниатюра/инициалы. Чужие аккаунты не читаются. Если сам источник маленький, нужно назначить контакту качественное фото из галереи.

## Подготовленное оформление (без сборки APK)

Сине-бело-голубая палитра со светлым и ночным вариантами. Обновлены история, контакты и поиск, клавиатура с буквами T9, карточка и редактор контакта, группы настроек, экран разговора, пустые состояния и системные панели. Смысловые цвета вызовов и кнопок ответа/отбоя сохранены. Иконка приложения использует переданный пользователем PNG Icons8 без изменения рисунка, в адаптивной белой подложке. Исходник 96×96; новая детализация не добавлялась. Сборка APK и проверка интерфейса на устройстве не выполнялись по просьбе пользователя.

## 0.5

Фото/инициалы контактов в каждой строке журнала, фильтр «Все / Пропущенные», компактные строки и кнопка сведений. Удаление: раскрыть запись → «Удалить вызов», либо долгое нажатие → «Удалить», либо «Править» для выбора нескольких. Всегда требуется подтверждение. При отсутствии WRITE_CALL_LOG запрашивается разрешение; удаление ограничено выбранными ID, результат перечитывается у системного провайдера. Свайп звонка отключён во время выбора записей. Тема вручную: настройки → Как в системе / Светлая / Тёмная; выбор сохраняется, применяется к Compose, системным панелям и диалогам. Круглые клавиши, отдельная круглая кнопка вызова с SIM под ней и синяя навигация без цветной капсулы. Требуется проверка на Samsung A15.

## 0.6: упорядоченные списки

Контакты отображаются единым блоком с тонкими разделителями, уменьшенными аватарами и более лёгким вторичным текстом. Алфавит показывает только буквы, присутствующие в результате поиска. В журнале каждый вызов остаётся отдельным, строки группируются по локальной дате («Сегодня», «Вчера», дата); время справа. Переключатель «Все / Пропущенные» объединён, навигация использует контурные значки. Устранён источник синих полос: фон действия свайпа больше не увеличивает высоту строки и скрыт в покое. Ручные темы и удаление сохранены.
