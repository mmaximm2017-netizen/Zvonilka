# Звонилка 0.3

Нативная звонилка для проверки на Samsung A15 / Android 16.
Техническая база: Kotlin 2.1.20, Jetpack Compose, Material 3, Android Telecom.

## Реализованный пакет

- Три вкладки: Недавние (стартовая), Контакты, Клавиши; системная светлая/тёмная тема.
- Каждая запись CallLog отдельно: тип, цвет, дата, время, длительность, доступная метка SIM.
- Раскрытие записи, повторный звонок, копирование, переход к контакту.
- Выбор записей долгим нажатием, подтверждение выбранного/полного удаления.
- Алфавитный список локальных RawContacts, поиск по имени/номеру, буквенная навигация.
- Внутреннее создание/редактирование имени, нескольких номеров, основного номера, фото из галереи.
- Карточка: фото-баннер, звонок, внешний SMS, копирование, редактирование, история и подтверждение удаления.
- Почти полный свайп вправо (82%) для звонка; возврат короткого свайпа; влево ничего не удаляется.
- T9 с русскими и латинскими буквами; результат только подставляет номер; зелёная кнопка звонит отдельно.
- Долгое 0 для +, удаление/полная очистка, вставка удержанием поля номера, нормализация российского 8/+7.
- SIM по умолчанию, выбор удержанием зелёной кнопки, память фактически использованного аккаунта после соединения.
- Фото-фон с center crop на экране вызова; приём и отклонение длинным свайпом.
- Ответ из баннера открывает CallActivity; mute, динамик, аудиовыход, DTMF, удержание, добавление вызова.
- Датчик приближения во время активного разговора через разговорный динамик, если датчик поддерживается.
- Переворот после наблюдавшегося положения экраном вверх запрашивает silenceRinger у Telecom.
- Собственные уведомления пропущенных: объединение по номеру, закрытие, обратный вызов.
- Открытие Недавних убирает уведомления пропущенных.
- Ручной VCF: экспорт имён и номеров; подтверждаемый импорт UTF-8 v3/v4 (до 5 МБ, 2000 контактов).
- Исправления очистки зависших уведомлений 0.2.1 сохранены.

## Границы и незавершённые пункты ТЗ

- SIM-01..07: прямое чтение/объединение/редактирование SIM-контактов не реализовано. Отображаются только контакты
  с account_type NULL или Samsung `vnd.sec.contact.phone`. Google/другие аккаунты не изменяются и не копируются.
- CON-08: выбор/замена фото есть; ручной crop пока отсутствует. Фото отображается с center crop.
- REC-09/10: долгий тап включает выбор; действия удаления находятся на панели, отдельного меню ⋮ пока нет.
- MIS-04: уведомления убираются; цифровой бейдж вкладки пока не реализован.
- INC-07: поворот из вертикального положения сразу экраном вниз без замеченного положения вверх не распознаётся.
- INC-08: принудительное немедленное выключение дисплея после отклонения не реализовано.
- CALL-04: финальная длительность показывается около секунды; точность при завершении в фоне требует проверки.
- SET-01: VCF переносит имена/номера, не фотографии. Импорт не заменяет записи и может создать дубликаты;
  при ошибке пишет число уже добавленных контактов. Сложные/старые vCard с quoted-printable не поддерживаются.
- SET-02/03: еженедельные копии и ротация трёх файлов не реализованы.
- CID-01..05: онлайн-поставщик не выбран; онлайн-запросы отсутствуют, INTERNET не запрашивается.
- compileSdk/targetSdk остаются 35, minSdk 29; выполнение на Android 16 требует реального теста.
- Постоянная подпись APK не настроена: может потребоваться переустановка и повторные разрешения.
- Репозиторий на момент разработки публичный. Настройка приватности не изменялась.

## Приёмка

На реальном телефоне необходимо проверить до постоянного использования:
1. Роль звонилки, права на контакты/журнал/телефон/уведомления и полноэкранные уведомления.
2. Исходящий, входящий при блокировке и поверх другого приложения; оба способа завершения, пропущенный.
3. Фото, длинные свайпы, физические кнопки громкости, переворот, датчик приближения.
4. Mute, динамик, DTMF, Bluetooth, удержание/второй вызов, две SIM, возврат в исходное приложение.
5. Контакт с двумя номерами: создать, сменить основной, добавить фото, изменить, удалить с подтверждением.
6. История: отдельные записи, цвета, раскрытие, свайп, подтверждение удаления, уборка пропущенных.
7. VCF на тестовых контактах: экспорт/импорт, русский текст, несколько номеров.

Не звонить на экстренные номера ради проверки. Экстренный UI обслуживает предустановленная звонилка.

## 0.3.1: диагностика стандартного экрана на Samsung

На Samsung A15 Android 16 подтверждён показ системного экрана при назначенной роли Звонилки. Точная причина пока не установлена. Эта сборка отделяет ошибки уведомления от обработки Telecom и открытия CallActivity, отменяет старое уведомление перед сменой его канала, сохраняет ограниченный локальный журнал подключения службы, состояний и ошибок. Настройки → Диагностика звонков → Копировать. Журнал не содержит номеров, имён контактов и сообщений исключений; автоматически никуда не отправляется. Обработчик необработанного исключения передаёт управление штатному обработчику Android. Требуется повторить обычный исходящий вызов на устройстве и проверить экран/журнал; сборка не является подтверждённым исправлением причины.

## 0.3.2: качество фото

Экран звонка и большой баннер контакта асинхронно читают RawContacts.DisplayPhoto вместо растягивания DATA15 (миниатюры). Размер декодирования ограничен 2048 пикселями по длинной стороне без увеличения маленького исходника; списки продолжают использовать миниатюры. При отсутствии большого фото или доступа остаётся миниатюра/инициалы. Чужие аккаунты не читаются. Если сам источник маленький, нужно назначить контакту качественное фото из галереи.

## 0.5

Фото/инициалы контактов в каждой строке журнала, фильтр «Все / Пропущенные», компактные строки и кнопка сведений. Круглые клавиши, отдельная круглая кнопка вызова с SIM под ней и синяя навигация без цветной капсулы. Требуется проверка на Samsung A15.

## 0.6: упорядоченные списки

Контакты отображаются единым блоком с тонкими разделителями, уменьшенными аватарами и более лёгким вторичным текстом. Алфавит показывает только буквы, присутствующие в результате поиска. В журнале каждый вызов остаётся отдельным, строки группируются по локальной дате («Сегодня», «Вчера», дата); время справа. Переключатель «Все / Пропущенные» объединён, навигация использует контурные значки. Устранён источник синих полос: фон действия свайпа больше не увеличивает высоту строки и скрыт в покое. Ручные темы и удаление сохранены.

## 0.7: три правки и бесплатная проверка спама

Уменьшен отступ над первым днём журнала, у номера контакта нулевая межбуквенная разрядка, неизвестный контакт обозначается силуэтом.

Опциональная проверка неизвестных входящих через публичный `/api/num` PhoneBlock (https://phoneblock.net/phoneblock/). Выключена по умолчанию. При включении сервис получает номер и IP; список контактов/журнал не отправляется. Публичный API не требует ключа по коду NumServlet; хеш-API требует авторизации и не используется. Источник и документация: https://github.com/haumacher/phoneblock/blob/master/INTEGRATIONS.md и https://github.com/haumacher/phoneblock/blob/master/phoneblock/src/main/java/de/haumacher/phoneblock/app/api/NumServlet.java . Реализация клиента собственная; код провайдера не копировался.

Это только сообщения о возможном спаме, не имена организаций и не подтверждение безопасности. Предупреждение требует совпадения полного номера, >=4 прямых голосов, отсутствия archived/whiteListed. Префиксные совпадения не используются. Ничего не блокируется. Лимиты: тайм-ауты подключения/чтения 2.5 с, ответ до 32 КиБ, до 100 результатов в памяти на 6 часов, пауза 1 час после HTTP429. Поиск вне главного потока; поздний результат привязан к UUID живого вызова. Доступность API и полнота российских номеров на устройстве пока не подтверждены.

## 0.8: подпись, фото, SIM и управление одной рукой

Начиная с 0.8 пользовательские APK подписываются постоянным приватным ключом вне GitHub, `scripts/sign-apk.sh` проверяет публичный отпечаток из `signing-certificate.sha256`. CI выдаёт только входные файлы (APK с временной debug-подписью и apksigner.jar); эти файлы НЕ выдавать пользователю как финальный релиз. Для выпуска скачать артефакт и выполнить скрипт с ZVONILKA_KEYSTORE / ZVONILKA_PASSWORD_FILE, затем проверить подпись. Никогда не генерировать новый ключ при его отсутствии: восстановить существующий приватный пакет Zvonilka-signing-private.zip из защищённого хранилища владельца. Переход с 0.7 требует переустановки, последующие APK с этим сертификатом совместимы для обновлений. Ключи/пароли запрещено коммитить, публиковать в CI или артефактах GitHub.

Редактор фото: панорамирование, масштаб 1–4×, сброс и предпросмотр кадра 9:20 с расположением имени/управления. Исходник и кадр хранятся в приватной памяти приложения; кадр также записывается в контакт. При изменении миниатюры другим приложением сохранённый кадр перестаёт использоваться. Это рабочие данные приложения, резервные копии НЕ добавлялись.

SIM: показываются слот/оператор, когда Android предоставляет эти данные; иначе исходное имя телефонного аккаунта. Обычное нажатие на подпись под кнопкой вызова и в карточке контакта открывает выбор SIM с отметкой текущей; можно вернуть выбор по умолчанию. Недоступная сохранённая SIM явно отмечена.

Управление вызовом перенесено вниз. Отдельные зелёный и красный ползунки с подвижной круглой ручкой требуют почти полного движения; обычное нажатие не отвечает/не отклоняет. Действия доступны через accessibility custom actions. При недостатке высоты остаётся прокрутка. Исправлено использование старого фото при переключении на неизвестного собеседника.

## 0.9.1 — входящий вызов поверх блокировки
- Явный creator BAL opt-in на Android 15+ только для immutable PendingIntent экрана звонка.
- При переходе в RINGING InCallService открывает экран один раз, если телефон заблокирован/погашен и разрешены уведомления, полноэкранные вызовы и высокий приоритет канала. Пользовательские запреты не обходятся.
- На главном экране и в настройках показано, какого разрешения не хватает, с переходом в соответствующие системные настройки.
- Публичная версия уведомления показывает сам факт вызова без имени и номера; системная политика блокировки сохраняется.
- Диагностика содержит состояние блокировки, разрешений и канала. Причина на конкретном устройстве без лога не установлена; требуется проверка заблокированного Samsung A15.

## 0.10 — оставшиеся функции данных
- Бейдж пропущенных на «Недавних» обновляется по сохранённому счётчику; просмотр обнуляет его и уведомления.
- Возвращена финальная длительность разговора; снимок длительности фиксируется при удалении вызова Telecom, в том числе когда экран был в фоне.
- SIM-книга ADN через SimPhonebookContract (Android 12+): чтение, объединение по нормализованному номеру с приоритетом локальной записи, пометка SIM, выбор источника при редактировании/удалении. Создание через + с выбором телефона/SIM. SIM хранит один номер и имя, без фото. Изменения проверяют свежий снимок записи; ограничения имени/номера валидируются до записи. Поддержка зависит от устройства/SIM и требует тестирования.
- VCF 2.1/3/4, quoted-printable с CHARSET, вложенные фото base64/data URI, перенос строк, корректная предпочтительность номеров. Внешние URL фото не загружаются. Ручной экспорт только локальных контактов включает фото, уменьшенные до 720 px по длинной стороне. Импорт валидирует изображения до подтверждения и пропускает точные совпадения имени и набора номеров.
- Ограничения VCF: 2000 контактов, входной файл 32 МБ, 12 МБ фото суммарно, отдельное фото до 512 КБ. Существующие контакты не заменяются; импорт не транзакционный, при ошибке указывается количество уже добавленных.
- Автоматические копии не добавлены по решению пользователя. Определитель организаций не реализован: бесплатный подтверждённый источник не выбран. PhoneBlock остаётся опциональной проверкой спама.
- Исправление блокировки 0.9.1 сохранено; на устройстве пользователем ещё не проверено.

## 0.10.1 — слайдер и единые уведомления
- Убрана красная кнопка над слайдером входящего вызова и из предпросмотра фото. Отбой активного/исходящего разговора сохранён. Отклонение клавишами громкости сохранено по прежнему решению пользователя; системная кнопка питания не перехватывается.
- Защищённый SystemMissedReceiver объявляет обработку ACTION_SHOW_MISSED_CALLS_NOTIFICATION нашей звонилкой. Счётчик увеличивает только InCallService, не дублирующий broadcast.
- После собственного уведомления, его закрытия и просмотра журнала вызывается TelecomManager.cancelMissedCallsNotification под проверкой defaultDialerPackage. Нулевой ответ Telecom не очищает собственный непрочитанный счётчик. Поведение Samsung требуется подтвердить на устройстве.
